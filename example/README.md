# manyui example

A gallery of the widgets in `manyui` v0.1.1.

```sh
flutter run -d chrome     # web
flutter run                # desktop / mobile, whichever device is selected
```

The gallery uses `MWidgetsApp` and `MScaffold`, with a theme toggle and
sidebar navigation. The Layout, Forms, Overlays, Navigation, and Feedback
pages each show their widgets in at least two states.

# manyui_assets

Optional Latin Modern Roman, Inter, and JetBrains Mono fonts for
[manyui](https://github.com/ManyMath/ManyUI). Add this package to use the
ManyMath typefaces; core `manyui` does not require them.

The font software retains its upstream licenses, separate from this package's
original MIT-licensed integration code. Inter and JetBrains Mono use OFL-1.1;
Latin Modern Roman uses the GUST Font License. See `NOTICE` and the exact license
files under each font directory. Those notices and provenance files are declared
Flutter assets, so application bundles retain the text as well as the font bytes.
Per-family provenance records the preserved binaries, inspected metadata and
immutable license source; historical unpinned retrieval/conversion is documented.
